Craftisle Viewer

Craftisle Viewer renders a file inside the browser tab instead of asking you to install an office suite. The accepted-extension list holds more than 130 formats, and PDF, DOCX, DWG, STL, EPUB and ZIP all open in place — each through a renderer written for that format rather than a generic text dump. Nothing is converted or re-exported: the file opens as it is. The toolbar offers download, print and HTML export.

What it opens

  • PDF and Office documents. PDF pages, DOCX and legacy DOC files, and PPTX decks render in dedicated viewers rather than as raw text. Spreadsheets — XLSX, XLS, XLSM, XLSB, CSV, ODS and Numbers — keep their rows, columns and cell values.
  • CAD and 3D models. Over forty CAD and 3D extensions are handled. STL, GLTF, STEP and DWG files can be rotated and inspected without a CAD package installed.
  • Books and archives. EPUB and UMD books open with their table of contents; ZIP, 7z, RAR and TAR archives are listed file by file instead of being downloaded blindly.
  • Data and media. Markdown, JSON and YAML get their own readers, and MP4 and MP3 play in the page.

How it works

The file is read through the browser's FileReader and rendered locally, so opening a document does not post it to a server, and there is no account to create. The viewer is a viewer only: it does not edit, convert or re-export the document. A few older formats are not in the accepted list — legacy .ppt, .odt and .rtf will not open, and neither will design files such as .psd or .ai.

Questions

What formats can I open?

PDF, DOCX, DOC, PPTX, XLSX, XLS, CSV, ODS, EPUB, ZIP, Markdown, JSON, images, MP4, MP3 and more than forty CAD and 3D extensions including STL, GLTF, STEP and DWG — over 130 in total.

Is my file uploaded?

No. The file is read in the browser to draw it on screen; there is no upload step and no account, so the document stays on the machine you opened it from.

Does it work on a phone?

Yes. The page is responsive and accepts touch input, so a PDF, a Word document or a 3D model can be opened on a phone or tablet without an office suite.
